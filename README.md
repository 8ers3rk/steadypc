# SteadyPC

Локальная диагностика и аккуратная настройка Windows. SteadyPC читает состояние системы, объясняет найденные проблемы и применяет только те изменения, которые вы выбрали вручную.

Приложение работает полностью офлайн: без телеметрии, без аккаунта, без облачных сервисов и без загрузки ресурсов из интернета.

## Скачать

Готовые сборки для Windows x64 находятся в [последнем релизе](https://github.com/8ers3rk/steadypc/releases/latest): установщик `SteadyPC-Setup-1.1.0.exe` и портативная версия `SteadyPC-Portable.exe`. Сборки не подписаны сертификатом; контрольные суммы SHA-256 указаны в примечаниях к релизу.

## Что SteadyPC делает

- Сканирует автозагрузку, диски, питание, процессы, сеть, визуальные эффекты и состояние обновлений.
- Показывает не только «найдено N проблем», но и причину каждой находки, исходные данные и предлагаемое действие.
- Выводит **все проверки** со статусом: «проблем нет» или «найдена проблема», с фактическими числами и порогами.
- Предоставляет вкладку **«Инструменты»**: любую операцию можно запустить вручную, независимо от результатов сканирования.
- Позволяет снять галочку с любого предложения: пресеты — лишь рекомендации, а не обязательный набор.
- Применяет выбранные изменения с журналом и, где это возможно, с откатом.
- Повторно сканирует систему после применения и показывает сравнение «до/после».
- Сохраняет исходные значения реестра и настроек, чтобы изменение можно было отменить.
- Открывает встроенную справку кнопкой «?»: что приложение делает, чего от него ждать и как оценивать обещания других программ.

## Чего SteadyPC не делает

Приложение намеренно **не** содержит типичных «бустерных» приёмов:

- не чистит реестр;
- не «очищает оперативную память»;
- не удаляет Prefetch;
- не удаляет системные файлы без проверки возраста;
- не отключает службы и телеметрию по умолчанию;
- не обещает фиксированный прирост FPS или скорости интернета;
- не завершает сторонние процессы без вашего участия.

Если метрика после изменения не улучшилась, SteadyPC прямо сообщает об этом.

## Индикаторы риска — не антивирус

SteadyPC выполняет восемь дополнительных офлайн-проверок: признаки майнеров в процессах, подключения к портам пулов, процессы в пользовательских каталогах без подписи, маскировка под системные процессы, закодированные команды PowerShell, необычная автозагрузка, задания планировщика и состояние встроенной защиты Windows.

- Совпадение признаков называется **индикатором риска**, а не «найденным вирусом». Это повод проверить путь, подпись и командную строку, а не приговор.
- Находки этой категории **не влияют на общий балл** и никогда не попадают в план изменений. У них нет кнопки применения.
- Приложение **не завершает процессы, не удаляет файлы и не помещает ничего в карантин**. В карточке доступны только безопасные действия: показать объект в Проводнике, скопировать собранные данные и открыть диспетчер задач.
- Уровень уверенности (`high`, `medium`, `low`) определяет текст рекомендации: от проверки другим инструментом до простого наблюдения. Ответственность за решение остаётся у вас.
- Признаки хранятся в `electron/security-signatures.json` внутри приложения. Дополнить их можно вручную в `%APPDATA%\SteadyPC\security-signatures.json`: файл объединяется со встроенным списком, сеть не используется. Если в файле ошибка, сканирование продолжается с предупреждением.
- Состояние встроенной защиты показывается как нейтральная информация, а не как оценка безопасности системы.

## Доступные проверки

| Категория | Пример находки | Действие |
|---|---|---|
| Автозагрузка | сторонняя программа при входе в систему | отключение с сохранением исходной записи |
| Диск и файлы | старые временные файлы, старый кэш обновлений | удаление только файлов старше заданного возраста |
| Накопитель | TRIM отключён на SSD, фрагментация HDD | TRIM или дефрагментация только для нужного типа диска |
| Питание | план энергии ограничивает CPU | смена плана с возвратом прежнего |
| Сеть | нестандартная автонастройка TCP, большой DNS-кэш | исправление настроек, очистка кэша |
| Внешний вид | включены анимации интерфейса | отключение с откатом |
| Процессы | высокая загрузка ОЗУ | только информация, без автоматического закрытия |
| Обновления | требуется перезагрузка | отдельная кнопка с подтверждением |
| Приватность | уровень телеметрии Windows | только информация, без изменения политики |
| Индикаторы риска | признаки майнеров, необычные процессы, автозагрузка, задания | только диагностика и безопасные кнопки, без удаления |

Все перечисленные проверки отображаются на экране диагностики даже в том случае, когда проблема не найдена. Там же указано, какое значение проверялось и почему оно не превысило порог.

На вкладке «Инструменты» доступны те же операции вручную: очистка временных файлов, кэша обновлений и DNS, TRIM для SSD, дефрагментация HDD, смена плана питания, сброс TCP и отключение анимаций. Дефрагментация блокируется на SSD, а TRIM — на HDD. Операции с правами администратора не запускаются тихо: приложение предлагает перезапуск от имени администратора.

## Безопасность

- Приложение запускается как обычный пользователь. Права администратора требуются только для конкретных операций.
- Перед изменением создаётся журналная запись. Для обратимых действий сохраняются исходные значения.
- Кнопка отката доступна в разделе **Журнал**.
- Перед изменениями среднего и высокого риска SteadyPC пытается создать точку восстановления Windows. Если это не удалось, приложение сообщает об этом и продолжает только выбранные вами операции.
- Все команды выполняются через типизированный реестр команд без вызова shell.
- Для индикаторов риска нет операций удаления, завершения процессов и карантина — только просмотр, копирование данных и открытие диспетчера задач.

## Установка и сборка

Требования:

- Windows 10/11 x64;
- Node.js 18+;
- npm.

```bash
npm install
npm run electron:dev
```

Сборка установщика и portable-версии:

```bash
npm run electron:build
```

Готовые файлы появятся в папке `release/`.

Проверки перед релизом:

```bash
npm run typecheck
npm test
npm run build
```

## Запуск с правами администратора

Часть действий требует прав администратора. Если вы выбрали такое изменение, SteadyPC предложит перезапустить приложение от имени администратора. После перезапуска повторите сканирование и применение.

Первые публичные сборки **не подписаны кодовым сертификатом**. Windows может показывать предупреждение SmartScreen. Проверяйте контрольные суммы релиза и скачивайте файлы только из официального репозитория. Подпись планируется добавить в одном из следующих релизов.

## Структура

```text
electron/
  main.js            IPC и жизненный цикл приложения
  preload.js         безопасный мост renderer → main
  collectors.js      только чтение состояния системы
  security.js        офлайн-эвристики индикаторов риска
  security-signatures.json  встроенный список признаков
  finding.js         фабрики находок и проверок
  commands.js        реестр изменений, откат, журнал операций
  scoring.js         прозрачная оценка состояния
  plan.js            пресеты и предпросмотр плана
  journal.js         сохранение истории изменений
src/
  components/        интерфейс и экраны приложения
  lib/api.ts         типизированный доступ к IPC
  types.ts           контракт между main и renderer
  i18n.ts            русская и английская локализация
  faq.ts, faq-content.json  встроенная справка на двух языках
tests/               тесты чистой логики
scripts/             вспомогательные скрипты
```
