# Changelog

## [1.2.0] - 2026-11-24

### Added

- Content Security Policy for the renderer: local scripts only by hash or bundle, no external frames, objects, workers or network destinations.
- Strict validation for every IPC argument and command parameter, including registry paths, startup entries, drive letters, power plans, preset IDs and finding IDs.
- Local structured logs in `%APPDATA%\SteadyPC\logs\` with rotation and sanitized values.
- Private JSON and escaped HTML export of the scan report, comparison data and change journal through a native save dialog.
- An in-app explanation that risk indicators are not an antivirus, plus a FAQ section on that limitation.

### Changed

- Replaced high/medium/low confidence wording with descriptions of the actual signals and recommended checks.
- Renamed the score as an author-made settings score and documented that it is not a Windows health metric or a performance promise.
- Presets now show their description in the plan view and are explicitly described as selectable recommendations.

### Security

- Renderer input can no longer choose arbitrary command parameters or safe-action targets.
- Report exports stay local and contain no external resources.
- The packaged renderer uses a production CSP with `connect-src 'none'`; the local Vite socket is allowed only in development.

### Fixed

- Registry startup actions generated by the collector are now validated correctly: the trailing colon in `HKCU:`/`HKLM:` is normalized, and HKLM entries require admin rights.
- Concurrent apply, tool and rollback requests can no longer run at the same time and duplicate changes.
- Startup shortcuts in redirected folders (for example OneDrive) are validated against the actual folder reported by Windows.
- HTML reports now include the local log path, comparison data and the correct `lang` attribute.

## [1.1.0] - 2026-11-24

### Added

- Eight offline risk-indicator checks for miners, suspicious processes, startup entries, scheduled tasks and built-in protection state.
- A built-in signature list with an optional manual override at `%APPDATA%\SteadyPC\security-signatures.json`; no network is used.
- Safe actions on indicator cards: reveal the file, copy evidence and open Task Manager.
- An in-app FAQ in Russian and English with no external links or product names.
- Tests for signature merging, heuristic confidence rules, score isolation and FAQ content.

### Changed

- Risk indicators are diagnostic only: they do not affect the health score, cannot be applied as changes and never trigger removal, process termination or quarantine.

## 1.0.0

- Rewritten as SteadyPC: offline diagnostics with detailed, evidence-based findings.
- Added real collectors for startup, storage, power, processes, network, visual effects, updates, and privacy.
- Added selectable change plans with presets as recommendations.
- Added command registry, journal, and rollback for reversible actions.
- Added before/after comparison after applying changes.
- Added an all-checks view with status, measured values, and thresholds for every collector.
- Added a Tools tab with manual access to every operation, guarded by media type and admin checks.
- Fixed temporary file reporting: total size and old-file counts were previously calculated incorrectly.
- Added transparent scoring with per-category breakdown.
- Added light and dark themes plus Russian and English UI.
- Removed Supabase, network fonts, demo mode, and unused dependencies.
- Removed placebo optimizations such as Prefetch deletion and registry cleaning.
- Added tests and GitHub Actions workflow.
- Added application icon and unsigned NSIS/portable builds.
